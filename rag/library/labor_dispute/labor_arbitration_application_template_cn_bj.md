# 劳动人事争议仲裁申请书模板 - 本地初始化摘要

本地文件用于初始化 Demo RAG。模板本体在 agent 包内的 `src/legal_agent/document_templates/templates/labor_arbitration_application.cn-bj.md`，RAG 中只保存模板来源和结构摘要。

## 劳动人事争议仲裁申请书模板#sections

劳动人事争议仲裁申请书通常包括申请人、被申请人、仲裁请求、事实与理由、证据和证据来源、提交机构、签名和日期。

适用要点：用于校验生成文书栏目是否完整。

## 劳动人事争议仲裁申请书模板#applicant

申请人信息通常需要姓名、身份证号、联系电话和住址等字段；缺失字段应标记为待补充。

适用要点：用于 ASK_USER 节点和草稿字段完整性检查。

## 劳动人事争议仲裁申请书模板#respondent

被申请人信息通常需要单位名称、统一社会信用代码、法定代表人或负责人、地址等字段；缺失字段应标记为待补充。

适用要点：用于 ASK_USER 节点和提交前人工复核。

## 劳动人事争议仲裁申请书模板#claims_and_facts

仲裁请求应尽量明确金额、期间和请求事项；事实与理由应围绕入职时间、劳动关系、工资标准、欠付期间、解除事实和证据来源组织。

适用要点：用于文书生成和 review 节点格式检查。

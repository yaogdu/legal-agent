# 工资支付暂行规定 - 劳动争议 Demo 关键条款摘要

本地文件用于初始化 Demo RAG。正文为面试 Demo 的条款摘要，正式生产库应替换为经校验的完整法规快照。

## 工资支付暂行规定#第六条

用人单位应向劳动者本人支付工资，并书面记录工资支付数额、时间、领取者姓名和签字等信息，相关记录依法保存备查。

适用要点：用于提示工资表、银行流水、工资条、电子支付记录等材料可作为工资支付事实证据。

## 工资支付暂行规定#第七条

工资应在用人单位与劳动者约定的日期支付，支付周期和遇节假日时的处理应依法执行。

适用要点：用于识别拖欠工资的时间点和拖欠期间。

## 工资支付暂行规定#第九条

劳动关系双方依法解除或者终止劳动合同时，用人单位应在解除或者终止劳动合同时一次付清劳动者工资。

适用要点：用于支持离职、辞退或解除劳动合同时追索欠付工资的请求。

## 工资支付暂行规定#第十八条

用人单位克扣或者无故拖欠劳动者工资等情形，劳动行政部门可以责令支付工资、经济补偿，并可责令支付赔偿金。

适用要点：用于提示欠薪事实除仲裁请求外，还可能涉及劳动行政投诉或监察路径。
